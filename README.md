# 陣格 FormationGrid

結合「野牛格」雙牛模式、荒野障礙與戰旗射程的手機邏輯益智遊戲。

## 規則

1. **佈陣**：10×10 戰場，每列、每欄、每個陣地剛好部署 2 個我方單位，共 20 個。
2. **間距**：我方單位不能相鄰（含斜角）；敵軍所在格不能部署。
3. **制壓**：每名敵軍都要落在至少一個我方單位的射程內。射程依朝向旋轉，不會被阻擋。
4. **兵力**：每關規定各兵種的精確數量，全部都要上場。

## 兵種（朝上時的射程）

| 兵種 | 射程 |
| --- | --- |
| 兵 步兵 | 正前方 1 格 |
| 弓 弓兵 | 正前方直線 3 格 |
| 劍 劍士 | 左前、正前、右前 3 格 |
| 騎 騎兵 | 前方日字跳躍 2 格（前 2、左右各 1） |
| 法 法師 | 左前、右前斜線各 2 格 |
| 將 將軍 | 前方 3 格、左右 2 格、正後 1 格 |

## 操作

- 點一下格子：部署目前選擇的兵種，預設朝上
- 按住格子往上下左右滑動：放開時朝向該方向；對已部署單位滑動可轉向
- 同兵種再點一次：撤下；「排除」「撤下」工具分別放記號、清除
- 鍵盤：Tab 移到格子後按方向鍵部署／轉向

## 開發

```bash
npm install
npm run dev
npm test
npm run build
```

## 題庫

`src/lib/source/hard-data.ts` 取自野牛格已凍結的雙牛 v1 題庫（每題唯一解）。`scripts/generate-levels.ts` 為每題隨機指派一組兵種與朝向，再從這組答案覆蓋到的非解答格中挑選敵軍，輸出 `src/lib/level-data.ts`：

- 敵軍只放在非解答格，所以單位位置維持唯一解，也能靠逐步推理解出。
- 每關由具體答案反推，保證存在能覆蓋全部敵軍且符合兵力限制的配置（兵種／朝向不要求唯一）。
- 優先挑選「能覆蓋它的選擇最少」的格子當敵軍，並確保該章的新兵種至少有一名專屬目標。

`npm test` 會驗證每關唯一解、答案合法，並用提示系統從空盤、轉錯方向、放錯位置等狀態自動解完。已發布的關卡 ID 不可重新生成覆蓋；改題請升級 ID（例如 `zhen-v2-*`）。

## 部署

`.github/workflows/deploy-pages.yml` 會在推送到 `main` 時測試、建置並發布到 GitHub Pages（Settings → Pages → Source 選 **GitHub Actions**）。Vite 使用相對路徑，不需依 repo 名稱調整。

本 repo 的 git 已在本地設定使用 personal SSH 金鑰（`core.sshCommand`）與 cacich 身分。
